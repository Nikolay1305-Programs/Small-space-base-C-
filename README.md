This is my university coursework project for Computer Graphics, which is an interactive 3D simulation of a futuristic space hangar built from scratch using C++ and OpenGL. In the project, you walk around the hangar in first-person view, complete with a patrolling droid, a parked spacecraft, and a control console. The main interaction works like this: you walk up to the console and click on it (using custom raycasting to detect clicks in 3D space), which triggers a countdown, opens the heavy hangar door with an animation, and launches the spacecraft toward Jupiter, which is visible in the distance.

To build this, I used OpenGL with custom GLSL shaders for lighting and texturing, GLM for mathematics and the camera system, and the SDL2 ecosystem for the window, input handling, on-screen dynamic text, and audio/music effects. (Note: While all the engine logic, shaders, and code are entirely my own, the 3D models for the ship, droid, and props were sourced externally from the internet).
